## GitHub 标签与版本自动化

原来 GitHub 只有 `v1.0.0`，产品基线为 `2.0.0`，Helm 仍为 `0.1.0`。现在根目录 `VERSION` 为唯一来源：

```bash
node scripts/version.mjs 2.0.1
```

一次命令同步 Go、前端 package/lock、Docker 开发版默认值和 Helm chart/appVersion；检查模式不写文件，禁止版本倒退。CI 成功后创建不可变附注标签，显式触发二进制和镜像发布；已有标签不移动。开发镜像使用 `main`，正式镜像更新 `latest`，Helm 默认使用 appVersion。详细规则和失败补跑方式见 [发布指南](../../RELEASE_GUIDE.md)。

自动化单元测试覆盖：成功创建标签、没有成功 CI 时拒绝、过期主分支提交跳过、不可信事件拒绝、既有标签保留、同提交重试、部分派发失败上报、版本同步和漂移拒绝。GitHub 实际发布由提交后的工作流执行。
