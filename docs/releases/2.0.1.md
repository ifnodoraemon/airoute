# Airoute 2.0.1

调试演练、副驾驶和接入引导现在直接使用登录会话与所选 API Key 调用，无需粘贴密钥明文。

- 选择 Key 同时决定模型权限、额度、计费分组和日志归属；后端实时检查归属、停用状态、钱包、预算与限流。
- 所有调试模态共用会话调用入口，包括 Gemini 原生请求、私有媒体、流式响应和视频任务轮询。
- 没有可用 Key 时引导创建，移除手工粘贴与免密选项及相关冗余代码。
- 上游 401 不再使控制台登录失效；公开 SDK 继续使用原有 API Key 鉴权，复制示例使用占位符。

实现与权限边界见 [控制台调用与 Key 选择](https://github.com/ifnodoraemon/airoute/blob/v2.0.1/docs/CONSOLE_AUTH.md)。
