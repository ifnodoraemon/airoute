# Airoute 2.2.2

修复路由思考配置列出全部统一档位、与实际上游能力不一致的问题。

- 默认思考模式、默认强度和允许范围根据已启用绑定渠道的能力显示；每个档位标明支持的渠道数量。
- 多渠道路由显示支持档位的合集，选定后仅调度支持该档的渠道，保持严格的请求与故障切换要求。
- 仅支持思考开关、没有可调强度的上游使用模型默认；未知或停用渠道不贡献可选档位。
- 失效的默认值和历史范围明确提示修正，保留原值，不自动降档或删除配置。
- 后端拒绝没有已启用上游支持的允许档位与模式；仅更新策略或绑定时也校验实际生效配置，避免绕过页面保存无效设置。
- 修复同时声明 OpenAI 与 Anthropic 原生协议的代理渠道强制使用 Messages、丢失 GLM 强度参数的问题；OpenAI 调用保留自身协议，Anthropic 入站仍使用原生 Messages。无法保真转换的思考参数明确拒绝。

配置说明见[统一思考配置](https://github.com/ifnodoraemon/airoute/blob/v2.2.2/docs/THINKING.md)。
