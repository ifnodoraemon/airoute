# Airoute 2.1.0

调试演练和副驾驶新增按实际上游能力显示的思考开关、强度与摘要选项，修复 Gemini 已有思考却没有请求展示摘要的问题。

- 能力配置统一放在「渠道 + 实际上游模型」，路由独立保存默认值与限制；模型别名在映射后判断能力。
- 调度在负载均衡前排除不能满足思考要求的渠道，重试和跨模型兜底保留原要求。
- 区分 DeepSeek 官方 API 与 GPUStack / vLLM 模板参数；代理忽略的开关不再作为已支持选项。
- 保留工具调用中的思考历史与原生签名，支持多轮回复继续调用。
- 展示思考用量、摘要是否返回和输出截断状态，请求日志记录最终生效配置与来源。
- 保留现有 SDK 原生参数透传；控制台继续使用登录会话和所选 Key ID，无需粘贴密钥明文。

配置、协议边界和真实渠道验证见 [统一思考配置](https://github.com/ifnodoraemon/airoute/blob/v2.1.0/docs/THINKING.md)。
