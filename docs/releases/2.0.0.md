# Airoute 2.0.0

## 升级说明

- 旧版 `POST /v1/completions` 已移除，使用 `/v1/chat/completions` 或 `/v1/responses`。仅声明退役协议的渠道会停用。
- 密钥创建统一使用 `POST /api/v1/admin/keys`，普通用户沿用所有权和自助配额限制；`GET /api/v1/user/keys` 保留。
- Skills/MCP 开关请求必须提供布尔值 `enabled`，错误或缺少参数不再隐式反转状态。
- 已发布标签和同名发布资产不覆盖；数据库升级与回滚边界见 [发布指南](https://github.com/ifnodoraemon/airoute/blob/v2.0.0/docs/RELEASE_GUIDE.md)。

## 主要变化

- 扩展原生 Google API、协议转译、资源与任务状态、上游并发控制。
- 支付订单支持幂等创建、通知与主动核验补偿、退款与争议额度调整，并隔离测试/生产环境。启用前按 [支付说明](https://github.com/ifnodoraemon/airoute/blob/v2.0.0/docs/PAYMENTS.md)完成商户测试环境验收。
- 渠道改名会在同一事务内迁移供应商报价；发生报价冲突时拒绝改名并整体回滚。
- 日志跳转调试器会选择原记录的模型与模态；Gemini 调试器显示安全拦截、长度上限及空响应原因。
- 累计 Tokens 与 TPM 上限分别显示；技能下载工件移除空转脚本并与页面说明保持一致。
- 认证页和登录弹窗共用认证流程，统一验证码、注册策略和一次性密钥交付。
- 重建脚本按实际存储配置选择依赖，并协调负载均衡容器设置。

## 版本与镜像

版本从根目录 `VERSION` 统一生成。主分支 CI 通过后自动创建版本标签、GitHub Release 和多架构镜像。`main` 是开发渠道，`latest` 是正式渠道；Helm 默认使用 chart 的应用版本。
