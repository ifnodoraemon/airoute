# Airoute 2.2.3

简化思考配置和调用操作，减少服务商、模型路由及对话页面的说明文字。

- 渠道按实际模型设置“支持关闭思考”和“支持档位”；开源部署与闭源 API 共用相同能力结构，参数适配收在高级设置。
- 调试演练、副驾驶和路由默认值使用一个思考选项，选档即开启；不支持的关闭或档位不出现。
- 渠道一次编辑一个模型，配置说明默认折叠，能力摘要只保留两项事实；增加表单区块间距。
- 精简演练参数名称、副驾驶欢迎语和执行状态，移除主界面的 Harness、协议和架构介绍。
- 保留失效选项提示和高级路由限制，避免简化界面时自动丢失已有要求。
- 允许只配置两个能力字段并继承协议适配，保留空档位集合及关闭能力的 JSON/YAML 语义。
- 修正 Ollama 兼容端点的思考参数，使用 `reasoning_effort`。
