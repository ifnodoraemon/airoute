# Airoute 2.2.0

让渠道模型的能力和买入价、公开路由的策略和对外售价在控制台中形成完整关系。

- 服务商、模型路由和定价页说明三层配置职责；路由展开后直接查看实际上游的思考开关、强度、能力来源与采购报价。
- 从路由或服务商进入采购报价表，自动定位渠道及实际模型；复用同一上游的多个公开别名共享报价，缺失报价明确提示。
- 采购报价新增币种、缓存读写报价和按次请求报价；区分未报价与已确认免费，兼容原有人民币 Token 报价。
- CSV 预览、导入和导出覆盖新增字段，保留九位小数、空值和整批回滚。
- 对外定价改用准确名称；路由参考售价使用后端计费引擎解析的精确/通配规则。不同币种、计费口径或停用报价不生成误导价差，系统兜底价格单独提示。
- 普通客户不展示采购入口，也不请求管理员采购接口。采购报价仍为参考，不改变客户扣费或路由调度。

升级自动执行数据库迁移 51，保留现有报价的人民币及 Token 计费含义，不虚构供应商合同价格。

配置说明：[统一思考配置](https://github.com/ifnodoraemon/airoute/blob/v2.2.0/docs/THINKING.md)、[渠道采购报价](https://github.com/ifnodoraemon/airoute/blob/v2.2.0/docs/PROCUREMENT.md)。
