# 渠道采购报价与对外售价

采购报价记录我们向供应商买入模型服务的合同参考单价。对外售价决定客户调用公开路由时的扣费；二者独立保存。

| 配置 | 归属 | 控制台入口 |
| --- | --- | --- |
| 思考能力、采购报价 | 渠道名称 + 映射后的实际上游模型 | 服务商 → 模型采购报价；模型路由 → 展开详情 → 配置采购报价 |
| 默认思考策略、对外售价 | 公开模型路由 | 模型路由 → 配置分发；模型定价 → 对外售价 |
| 统一采购报价表 | 所有渠道的模型 | 模型定价 → 渠道采购报价 |

一条公开路由可绑定多个供应商，每个渠道模型的采购价独立。一个渠道模型可被多条公开路由复用，采购报价共用一条。对照表沿实际绑定关系展示对应的公开模型，不按公开别名猜测采购价。没有绑定路由的历史报价仍保留；渠道改名会在同一事务内重绑报价。

## 报价字段

- `currency`：三位大写币种代码，旧数据默认为 `CNY`。
- `billing_mode`：`token` 或 `request`，旧数据默认为 `token`。
- Token 报价：`input_cost`、`output_cost` 必填，单位为指定币种 / 百万 Token。
- 缓存报价：`cache_read_cost`、`cache_write_cost` 可空，同样按百万 Token。空值表示未取得报价，显式 `0` 表示确认免费。未报价不会自动套用普通输入价，也不会改变客户的缓存计费。
- 按次报价：`fixed_cost` 必填，单位为指定币种 / 次请求。切换为按次报价时清除 Token 和缓存报价；切换回 Token 时清除按次价。
- `status`：`active` 或 `disabled`。停用报价保留展示，不参与价差对照。

存储使用对应币种的十亿分之一整数，保留九位小数。升级不填充或推测真实供应商价格，也不会发起付费上游探测。

## 价格对照

对外基准取公开路由的默认分组定价，由后端计费引擎解析精确规则或通配规则；界面标明继承规则。没有配置而使用系统兜底价格时明确提示，不当作已配置报价。

采购币种独立记录；当前客户钱包与对外定价仍以 CNY 结算。只对照币种和计费口径一致、启用的报价。不同币种不自动做汇率换算。按次采购价不能直接与按 Token 收费、混合收费或按图片数量计费的零售规则比较。

输入/输出的基准价差不包含客户分组、时段、缓存或实际调用用量，不代表实际利润。采购报价不写入调用成本、不改变钱包扣费、不影响路由调度。实际供应商账单仍在供应商对账中处理。

采购接口与报价表仅管理员可访问，普通客户页面不加载采购数据。

## 导入与导出

保留原接口 `/api/v1/admin/supplier-costs`，GET 列表、POST 保存、DELETE 删除；导入与导出位于 `/import`、`/export`。按 `channel`、`model` 唯一键覆盖保存。

CSV 表头：

```csv
channel,model,input_cost,output_cost,status,currency,billing_mode,cache_read_cost,cache_write_cost,fixed_cost
```

兼容旧版四列或五列人民币 Token 文件；扩展表头中可省略可选列，必填报价按计费方式验证。可选报价保留空白，导出再导入不会将空白变成免费。导入先预览校验，确认后整批提交；任何一行写入失败都会回滚本批次。标识符保留原有电子表格公式转义。
